# Task Timer ⏱

App minimalista de gestión de tareas con cronómetro integrado.

## Despliegue en Vercel (5 minutos)

### Paso 1: Subir a GitHub
1. Ve a [github.com/new](https://github.com/new)
2. Nombre del repositorio: `task-timer`
3. Dale a **Create repository**
4. En la página que aparece, haz clic en **"uploading an existing file"**
5. Arrastra TODOS los archivos y carpetas de este proyecto
6. Dale a **Commit changes**

### Paso 2: Desplegar en Vercel
1. Ve a [vercel.com/new](https://vercel.com/new)
2. Selecciona el repositorio `task-timer`
3. Framework Preset: **Vite** (lo detecta solo)
4. Dale a **Deploy**
5. En 1 minuto tendrás tu URL tipo `task-timer-xxx.vercel.app`

### Paso 3: Instalar como app en el móvil
1. Abre la URL en tu móvil
2. **iPhone**: Safari → Compartir → "Añadir a pantalla de inicio"
3. **Android**: Chrome → Menú (⋮) → "Añadir a pantalla de inicio"

¡Listo! Ya tienes tu app instalada.

## Funcionalidades
- Categorías con colores
- Tareas con cronómetro
- Historial de sesiones
- Datos persistentes (se guardan en el navegador)
- Funciona sin conexión (PWA)
- Modo oscuro / claro
- Exportar datos como JSON
